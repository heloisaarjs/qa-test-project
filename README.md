# QA Test Project - Login e Cadastro

## 📌 Objetivo
Simular o processo de QA em uma funcionalidade de cadastro e login de usuário, incluindo:
- User Stories
- Critérios de aceitação
- Casos de teste
- Relatório de bug

## 📌 Escopo
Testes funcionais manuais na funcionalidade de:
- Cadastro de usuário
- Login no sistema

## 📌 Tipos de teste aplicados
- Teste funcional
- Teste de validação de campos
- Teste negativo
- Teste de regressão (simulado)

## 📌 Ferramentas simuladas
- Azure DevOps (casos de teste)
- Jira (bug report)

Este projeto foi desenvolvido para prática e aprimoramento em QA.

## Estrutura do Projeto

- user-stories.md → Histórias e critérios de aceitação
- test-case.md → Casos de teste funcionais e negativos
- regression-test.md → Teste de regressão após correção de bug
- bug-report.md → Exemplo de abertura de bug
